# nuScenes camera-LiDAR pipeline check

Scripts that check a camera-first range-gated camera-LiDAR evaluation pipeline on the **nuScenes mini** split before any full study. The detectors are not trained for this setting (or are stand-ins), so the recall values produced here are mechanics checks, **not** scientific results.

## What is here
- `nus_pipeline_check.py` - stage 1: data loading, coordinate transforms, eligibility rules, the camera arm (COCO YOLO11n), a LiDAR stand-in (KITTI-trained PointPillars on converted nuScenes points) and the routing/fusion code, end to end
- `nus_pipeline_eval.py` - stage 2: verification checks and routing/fusion arms on the saved mini frames
- `patch_json_lidar.py` - adds an optional `NUS_LIDAR_JSON` input to stage 1 so the LiDAR arm can use an MMDetection3D `results_nusc.json`
- `colab/` - a Google Colab notebook (`run_mmdet3d_nuscenes.ipynb`, generated by `make_notebook.py`) that runs a nuScenes-trained PointPillars checkpoint with MMDetection3D 1.4.0 (torch 2.1.0+cu118, mmcv 2.1.0, mmdet 3.2.0) on a T4 GPU
- `results/` - the pipeline-check outputs

## Data
The nuScenes data are **not** included. Download them from [nuscenes.org](https://www.nuscenes.org) under its terms of use.
